### 🛠️ เทคโนโลยีที่ใช้ในการพัฒนา
- **Backend Framework:** Laravel 12 (PHP 8.2)
- **Database:** SQLite (พร้อมใช้งานทันที) และรองรับ MySQL / phpMyAdmin (ไฟล์ `database/phone_repair_database.sql`)
- **Frontend / Styling:** Bootstrap 5.3, Bootstrap Icons, Apple Minimalist Design System
- **Fonts:** Google Fonts (Prompt & Kanit)

### 🚀 วิธีการเปิดใช้งานระบบ (How to Run)

#### วิธีที่ 1: เปิดใช้งานผ่านคำสั่ง Laravel (แนะนำ - สะดวกและเร็วที่สุด)
1. เปิด Terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์:
   ```bash
   cd "c:\xampp\htdocs\Final Project\phone-repair"
   ```
2. รันเซิร์ฟเวอร์ด้วยคำสั่ง:
   ```bash
   php artisan serve
   ```
3. เข้าสู่ระบบผ่านเว็บเบราว์เซอร์:
   - **หน้าบ้าน (สำหรับลูกค้า):** [http://127.0.0.1:8000](http://127.0.0.1:8000)
   - **ระบบหลังบ้าน (สำหรับช่าง/แอดมิน):** [http://127.0.0.1:8000/login](http://127.0.0.1:8000/login)

#### วิธีที่ 2: รันผ่าน XAMPP (Apache & MySQL)
- สามารถนำไฟล์ฐานข้อมูล `database/phone_repair_database.sql` ไป Import ใน phpMyAdmin ของ XAMPP ได้ทันที

### 🌟 ฟังก์ชันเด่นของระบบ
1. **ระบบติดตามสถานะ (Live Repair Tracking):** แสดงแถบความคืบหน้า 5 ขั้นตอน (รับเครื่อง -> ตรวจเช็ค -> ดำเนินการซ่อม -> ซ่อมเสร็จ -> ส่งมอบ) พร้อมประวัติบันทึกการทำงานของช่างอย่างละเอียด
2. **ระบบแจ้งซ่อมออนไลน์ (Online Booking):** ลูกค้าสามารถเลือกรุ่น iPhone ระบุอาการเสีย และได้รับ Tracking Code ทันที
3. **เครื่องคำนวณราคาประเมิน (Price Calculator):** คำนวณราคาค่าซ่อมตามรุ่น iPhone และประเภทอาการเสียแบบไดนามิก
4. **ระบบจัดการหลังบ้าน (Back-end Management):** อัปเดตสถานะงานซ่อม กำหนดช่างผู้รับผิดชอบ คำนวณราคาจริง และพิมพ์ใบรับเครื่องซ่อมขนาดมาตรฐาน
5. **ระบบพิมพ์ใบรับเครื่องซ่อม (Printable Claim Slip):** มีเอกสารมาตรฐานพร้อมเงื่อนไขการรับประกันและช่องลงนามลูกค้า/ช่าง
